# How-to Guides

How-to guides are **task-oriented** recipes that help you solve specific problems. They assume you already have a working VlinderCLI setup and some familiarity with the basics.

## Guides

| Guide | What it covers |
|-------|---------------|
| [Installation](installation.md) | Building from source, prerequisites, bootstrap |
| [Configuration](configuration.md) | `config.toml` settings, environment variable overrides, logging, providers |
| [Manage Models](manage-models.md) | Add, list, and remove models from catalogs |
| [Storage](storage.md) | SQLite defaults, declaring storage in `agent.toml`, bring-your-own-storage |
| [Time-Travel Debugging](time-travel-debugging.md) | Timeline log, fork, resume, and diff workflows |
| [Observability](observability.md) | JSONL logs, `jq` recipes, NATS message tracing |
| [Distributed Deployment](distributed-deployment.md) | NATS setup, multi-process mode, worker scaling |
